# Investor Contact - Deployment Guide\n\nThis guide covers deploying the Investor Contact app to production using Vercel, Supabase, and Stripe.\n\n## Prerequisites\n\n- GitHub account\n- Vercel account (free)\n- Supabase account (free tier available)\n- Stripe account (free with live mode)\n- Code pushed to GitHub\n\n---\n\n## Step 1: Prepare Your Repository\n\n1. **Merge the branch to main**:\n   ```bash\n   git checkout main\n   git merge day1-day5-setup\n   git push origin main\n   ```\n\n2. **Verify `.gitignore` includes**:\n   ```\n   .env.local\n   .env*.local\n   node_modules/\n   .next/\n   ```\n\n3. **Never commit** sensitive files or `.env.local`.\n\n---\n\n## Step 2: Set Up Supabase for Production\n\n### Create a Production Project\n\n1. Go to [Supabase Dashboard](https://app.supabase.com)\n2. Click **New Project**\n3. Name: `investor-contact-prod`\n4. Region: Choose closest to your users\n5. Password: Generate strong password\n6. Click **Create new project**\n\n### Run Migrations\n\n1. In Supabase SQL Editor, run migrations in order:\n   - `supabase/migrations/001_billing.sql`\n   - `supabase/migrations/002_billing_rls.sql`\n\n2. Copy your project credentials:\n   - **Project URL**: Settings → API → Project URL\n   - **Anon Key**: Settings → API → `anon` public key\n   - **Service Role Key**: Settings → API → `service_role` secret key (for webhooks only)\n\n---\n\n## Step 3: Set Up Stripe for Production\n\n### Create Products and Prices\n\n1. Go to [Stripe Dashboard](https://dashboard.stripe.com)\n2. Navigate to **Products** → **Create Product**\n\n#### Product 1: Founder List\n- **Name**: Founder List\n- **Description**: Publish offers and stay visible to investors\n- **Pricing**: $9.99/month (recurring)\n- Copy the **Price ID** (e.g., `price_...`)\n\n#### Product 2: Investor Access\n- **Name**: Investor Access\n- **Description**: Browse offers and request contact\n- **Pricing**: $19.99/month (recurring)\n- Copy the **Price ID**\n\n### Get API Keys\n\n1. Go to **Developers** → **API Keys**\n2. Copy **Publishable Key** (starts with `pk_live_`)\n3. Copy **Secret Key** (starts with `sk_live_`)\n\n### Set Up Webhooks\n\n1. Go to **Developers** → **Webhooks**\n2. Click **Add Endpoint**\n3. **Endpoint URL**: `https://your-app-domain.vercel.app/api/stripe/webhook`\n4. **Events to send**:\n   - `checkout.session.completed`\n   - `customer.subscription.updated`\n   - `customer.subscription.deleted`\n5. Click **Add Endpoint**\n6. Copy **Signing Secret** (starts with `whsec_`)\n\n---\n\n## Step 4: Deploy to Vercel\n\n### Connect Repository\n\n1. Go to [Vercel](https://vercel.com/dashboard)\n2. Click **Add New** → **Project**\n3. Select your GitHub repository\n4. Click **Import**\n\n### Configure Environment Variables\n\nIn Vercel project settings → **Environment Variables**, add:\n\n**Supabase (Production)**\n```\nNEXT_PUBLIC_SUPABASE_URL = <your-supabase-url>\nNEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY = <your-anon-key>\n```\n\n**Stripe (Production)**\n```\nNEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY = pk_live_...\nSTRIPE_SECRET_KEY = sk_live_...\nSTRIPE_WEBHOOK_SECRET = whsec_...\nSTRIPE_FOUNDER_PRICE_ID = price_...\nSTRIPE_INVESTOR_PRICE_ID = price_...\n```\n\n**Site URL**\n```\nNEXT_PUBLIC_SITE_URL = https://your-domain.vercel.app\n```\n\n### Deploy\n\n1. Click **Deploy**\n2. Wait for build to complete (2-5 minutes)\n3. Vercel provides a production URL: `https://your-app-name.vercel.app`\n\n---\n\n## Step 5: Configure Custom Domain (Optional)\n\n1. In Vercel project settings → **Domains**\n2. Add your custom domain\n3. Follow DNS setup instructions\n4. Update Stripe webhook URL with new domain\n\n---\n\n## Step 6: Test Production\n\n### Email & Authentication\n- Sign up with a test email\n- Verify email confirmation (check Supabase auth logs)\n\n### Stripe Payments (Test Mode)\n- By default, Stripe operates in **Test Mode**\n- Use test card: `4242 4242 4242 4242`\n- Expiry: any future date\n- CVC: any 3 digits\n\n### Test Flow\n1. Sign up → Go to `/pricing`\n2. Click \"Subscribe as founder\" → Stripe checkout\n3. Use test card\n4. Complete payment\n5. Check Supabase `subscriptions` table for new row\n6. Visit `/dashboard` to see active plan\n\n### Switch to Live Mode\n- When ready, use live Stripe keys in Vercel env vars\n- Use real payment cards\n\n---\n\n## Step 7: Post-Deployment Checklist\n\n- [ ] Database migrations applied\n- [ ] Environment variables set in Vercel\n- [ ] Supabase Row Level Security enabled\n- [ ] Stripe webhooks configured\n- [ ] Custom domain configured (if applicable)\n- [ ] Test signup flow works\n- [ ] Test payment flow works\n- [ ] Emails sending (check Supabase/auth logs)\n- [ ] Check Vercel analytics/logs for errors\n- [ ] Test on mobile\n\n---\n\n## Monitoring & Debugging\n\n### Vercel Logs\n- Go to **Deployments** → click deployment → **Logs**\n- View real-time server logs\n\n### Supabase Logs\n- Go to **Logs** → view auth, database, API events\n- Check for RLS policy violations or auth errors\n\n### Stripe Logs\n- Go to **Developers** → **Events** to see webhook events\n- Check **Logs** for any failed requests\n\n---\n\n## Troubleshooting\n\n### Issue: Stripe webhook fails\n**Solution**: Verify webhook URL in Stripe dashboard matches your deployed URL\n\n### Issue: Auth not working\n**Solution**: Check Supabase credentials in `.env.local` match deployed values\n\n### Issue: RLS errors on queries\n**Solution**: Ensure migrations 002_billing_rls.sql was applied to production database\n\n### Issue: \"403 Forbidden\" on API routes\n**Solution**: Check CORS, verify Stripe secret key is set (not publishable key)\n\n---\n\n## Scaling & Maintenance\n\n- **Supabase**: Free tier supports ~50K monthly active users. Upgrade if needed.\n- **Stripe**: No limits, pay per transaction.\n- **Vercel**: Free tier includes 100GB bandwidth/month. Monitor usage.\n- **Database backups**: Supabase handles automatic backups.\n- **SSL/HTTPS**: Vercel provides free SSL certificates.\n\n---\n\n## Support\n\n- [Vercel Docs](https://vercel.com/docs)\n- [Supabase Docs](https://supabase.com/docs)\n- [Stripe Docs](https://stripe.com/docs)\n- [Next.js Deployment](https://nextjs.org/docs/deployment)\n"
